# 利用権限

本ファイルは、認証サーバーと参加アプリが共有する利用権限の仕様です。認証サーバーは参加アプリへの引き渡し可否を決めるときにこの実効権限を使い、参加アプリは各リクエストのアクセス可否を決めるときに同じ手順を使います。両者の手順を別々に実装・変更してはいけません。認証サーバー自身の画面と API は対象外で、管理操作は `User.role` で認可します。

## データ

`App` に nullable な `defaultPermission` を足します。既定なしは SQL `NULL` で表します。空文字列は有効な値ではありません。

`AppGrant` は今のとおりです。`userId` は必須で、一意制約は `(userId, appId)` です。一人の利用者と一つのアプリの組に、行は一枚です。

| 列 | 内容 |
| --- | --- |
| `App.defaultPermission` | `NULL`、または正の権限の一つ。`NULL` のアプリは、行がある人だけ入れる |
| `AppGrant.permission` | 正の権限の一つ、または `none` |

`none` は順位のある権限ではありません。その利用者だけを拒否する値です。既定には書きません。

行が無いことは、既定があるアプリでは「既定を使う」です。既定が `NULL` のアプリでは「入れない」です。

## 正の権限

正の権限は名前の一覧です。現在の一覧は `admin` と `user` です。`admin` が最上位です。

名前を足すときは、この一覧と、各参加アプリの画面の許可を同じ変更で更新します。列の型は変えません。一覧に無い文字列は正の権限ではありません。

| 値 | 位置 |
| --- | --- |
| `admin` | 最上位。下位の権限に開いている画面も開く |
| `user` | 下位 |
| 追加する名前 | 追加するときに、`admin` より下の位置と、開く画面を定める |
| `none` | 権限ではない。`AppGrant` だけに書く |

下位の権限同士の包含は、名前を足すときに定めます。定めていない画面は開きません。

## 実効権限

引数は `userId` と `appId` です。結果は、正の権限の一つ、または付与なしです。`User.role` は見ません。

```text
App が無い
  → 付与なし
AppGrant がある
  → permission が正の権限なら、その値
  → none、空、一覧に無い文字列なら、付与なし
    既定へは進まない
AppGrant が無く、defaultPermission が正の権限
  → その値
それ以外
  → 付与なし
```

例外の行は既定を置き換えます。既定より高い値も、低い値も、`none` も、行の値をそのまま使います。既定と行の高い方は取りません。

`User.role` が `admin` でも、実効権限は上記の結果です。既定が `user` で行が無い利用者は、認証サーバー上の管理者でも参加アプリでは `user` です。

`User.role` は認証サーバー自身の管理機能の認可にだけ使います。通常の認証操作はログイン状態とパスキー状態で判定します。認証サーバー自身への入場判定は本手順の対象外で、`AppGrant` を要求しません。一方、認証サーバーが参加アプリへの引き渡しを行う際は、本手順で対象アプリの実効権限を決めます。

## セッション

Redis のセッション値に、権限も `User.role` も載せません。既定の変更、行の追加、行の変更、行の削除は、次のリクエストから効きます。セッションの作り直しは要りません。

付与なしのときはセッションの TTL を延ばしません。

## 例

| 既定 | 行 | 実効権限 |
| --- | --- | --- |
| `user` | 無し | `user` |
| `user` | `admin` | `admin` |
| `user` | `none` | 付与なし |
| `NULL` | 無し | 付与なし |
| `NULL` | `user` | `user` |
| `user` | 一覧に無い文字列 | 付与なし |
| 一覧に無い文字列 | 無し | 付与なし |
| `admin` | 無し | `admin` |

最後の例では、パスキーがある利用者がそのアプリの管理者になります。付与一覧も開きます。

## 必須事項

- 実効権限の手順は、引き渡しと参加アプリで同じにする
- 利用者全員の `AppGrant` は作らない
- `userId` が空の `AppGrant` は作らない
- `NULL` を既定なしとして保存し、空文字列や `none` を既定に書かない
- 一覧に無い文字列は、行にあっても既定にあっても付与なしにする
- 参加アプリの画面・APIの許可に `User.role` を使わない
- `admin` は、下位の権限に開いている画面を開く
